
# Multi-LLM Chatbot

**An AI-powered chatbot built using Google Gemini API.**

## 📌 About The Project

Multi-LLM Chatbot is a web-based AI chatbot that uses the **Google Gemini API** to generate intelligent responses to user queries.

The project provides a simple and interactive interface where users can communicate with an AI model and get real-time responses.

I developed this project individually as a member of **MLCOE (Machine Learning Club of Excellence)**.

## ✨ Key Features

- AI-powered conversations using Gemini API.
- Real-time response generation.
- Interactive and user-friendly chat interface.
- Dynamic chat functionality.
- Clean and responsive UI.

## 🛠️ Technologies Used

- **HTML5** – Structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Chat functionality and API integration
- **Google Gemini API** – AI-generated responses

## 👨‍💻 My Contribution

**Role: Individual Developer**

I developed this project as an MLCOE member.

- Designed the chatbot interface using HTML.
- Created the layout and styling using CSS.
- Implemented chat functionality using JavaScript.
- Integrated Google Gemini API for AI-generated responses.
- Handled API requests and displayed generated responses in the chat interface.

## 🎯 Project Objective

To explore Generative AI and understand how frontend technologies can be integrated with Large Language Model APIs to build interactive AI-powered applications.

## 📚 What I Learned

- Working with Google Gemini API.
- JavaScript Fetch API and asynchronous operations.
- Integrating external APIs into web applications.
- Building interactive chatbot interfaces.
- Understanding practical applications of Generative AI.
